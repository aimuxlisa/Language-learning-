# PRD — LinguaQuest: AI-репетитор по английскому языку

**Версия:** 1.0 · **Дата:** 2026-11-13 · **Статус:** черновик к реализации MVP

## 1. Обзор

LinguaQuest — SaaS-платформа для изучения английского языка в игровой форме (в духе Duolingo), с AI-репетитором на базе Claude API, подготовкой к экзаменам (IELTS, ЕГЭ) и системой прогрессии из уровней, наград и ежедневных стриков.

**Целевая аудитория:** русскоязычные пользователи (школьники, готовящиеся к ЕГЭ; взрослые, готовящиеся к IELTS; все, кто учит английский «для себя»).

**Язык интерфейса:** русский. Изучаемый язык — английский.

## 2. Проблема и ценность

- Репетиторы дороги, групповые курсы негибкие, Duolingo не готовит к ЕГЭ/IELTS и не даёт глубокого разбора ошибок.
- LinguaQuest сочетает: игровую мотивацию (уровни, карточки-призы, стрики) + экзаменационные треки + персональный AI-разбор каждой ошибки.

## 3. Ключевые функции (MVP)

### 3.1 Аккаунты и ЛК
- Регистрация и вход (email + пароль; better-auth).
- Личный кабинет: прогресс, стрик, собранные карточки, статистика по навыкам, тариф.
- Выбор уровня сложности при онбординге (Beginner / Intermediate / Advanced) + мини-тест на определение уровня (опционально, 10 вопросов).

### 3.2 Треки обучения
- **Общий курс** — 20 уровней (MVP), от A1 до B2.
- **Подготовка к ЕГЭ** — задания в формате экзамена (в MVP: структура-заглушка + 2 демо-урока).
- **Подготовка к IELTS** — аналогично (2 демо-урока).

### 3.3 Структура уровня/урока
Каждый уровень = урок, содержащий:
1. **Теория** — короткий конспект (грамматика, лексика, правописание) с примерами.
2. **Практика** — 8–15 заданий разных типов:
   - квиз (один/несколько правильных ответов);
   - заполнить пропуск (grammar/spelling);
   - собрать предложение из слов;
   - перевод (проверка через AI);
   - **listening** — прослушать фразу (TTS) и записать/выбрать услышанное;
   - **speaking** — произнести фразу (Web Speech API → распознанный текст → оценка AI).
3. **Итог** — результат, разбор ошибок от AI, награда.

### 3.4 Прогрессия и геймификация
- Уровни открываются последовательно; уровень пройден при ≥70% правильных ответов.
- **Карточки-призы:** за каждый пройденный уровень открывается коллекционная карточка (персонаж/факт об английском). Коллекция видна в ЛК.
- XP за задания, стрик за ежедневный вход (daily check-in с бонусом XP).
- Шкала прогресса по навыкам: grammar, vocabulary, listening, speaking, spelling.

### 3.5 AI-функции (Claude API)
- **Разбор ошибок:** после урока Claude объясняет каждую ошибку по-русски и даёт рекомендацию.
- **Оценка speaking:** сравнение распознанного текста с эталоном, фидбек по лексике/грамматике.
- **Проверка свободных ответов** (перевод, письменный ответ).

### 3.6 Тарифы
| Тариф | Условия |
|---|---|
| **Free** | 5 уроков **или** 20 минут занятий в сутки; лимит сбрасывается каждые 24 часа; прогресс дальше 5-го уровня недоступен |
| **Pro** | Все уровни и треки без ограничений. Оплата — заглушка в MVP (кнопка «Скоро»), интеграция платёжки позже |

Лимит Free считается по скользящему окну 24ч от первого урока дня. UI показывает остаток лимита и таймер сброса.

## 4. Не входит в MVP
- Реальная оплата (Stripe/ЮKassa) — подготовить поле `plan` в БД и gate-логику, но без платёжного провайдера.
- Мобильные приложения, офлайн-режим.
- Соцфункции (лиги, друзья), пуш-уведомления.
- Полные банки заданий ЕГЭ/IELTS (только демо).
- Собственные STT/TTS-модели (используем браузерные Web Speech API).

## 5. Метрики успеха
- Активация: ≥60% зарегистрированных проходят урок 1.
- Retention D1: пользователь возвращается и получает стрик.
- Конверсия в интерес к Pro: клики по «Скоро» на пейволле.

## 6. Риски
- Web Speech API (распознавание речи) стабильно работает только в Chrome/Edge — для других браузеров speaking-задания помечаются «недоступно в вашем браузере» и пропускаются без штрафа.
- Стоимость Claude API — ограничить AI-вызовы (разбор 1 раз на попытку урока, кэш ответов).
- Контент 20 уровней — генерируется заранее и хранится статично (seed в БД), а не на лету.
